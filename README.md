# CRAZYBABY Luna – Futuristic Wireless Speaker  

A sleek and innovative **wireless speaker** with a **futuristic design** and **high-quality sound performance**. Luna features **aircraft-grade aluminum**, a **tweeter speaker system** for enhanced audio depth, and a **multiroom system** for seamless home integration.

- **SCSS (45.5%)** – modern styling and responsive design  
- **HTML (40.6%)** – structured and semantic page layout  
- **JavaScript (13.9%)** – interactive elements and user interface
